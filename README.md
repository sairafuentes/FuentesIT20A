\# SORTING ALGORITHMS



\## 1. Program Description



Kani nga Java program nagpakita kung unsaon pag-sort sa mga numbers gamit ang tulo ka sorting algorithms: Bubble Sort, Selection Sort, ug Insertion Sort. Ang program naay 10 ka lahi-lahi  nga numbers nga i-arrange gikan sa pinakagamay hangtod sa pinakadako. Ang kada algorithm naay kaugalingong method ug separate copy sa original array.



\## 2. How Each Sorting Algorithm Works



\### A. Bubble Sort



Ang Bubble Sort nagkumpara sa duha ka magtapad nga numbers. Kung mas dako ang number sa wala kaysa sa naa sa tuo, mag-ilis sila ug puwesto. Balik-balikon kini nga proseso hangtod mahan-ay ang tanan numbers gikan sa pinakagamay hangtod sa pinakadako.



\### B. Selection Sort



Ang Selection Sort mangita sa pinakagamay nga number sa array. Pag makita na ibutang kini sa unang puwesto. Aron mag sunod sunod ang puwesto mangita napud ug pinakagamay nga numbers.  Hangtod na dayon ma-sort na ang tanan numbers.



\### C. Insertion Sort



Ang Insertion Sort magkuha og isa ka number ug mangita sa sakto nga puwesto niini. I-compare ang number sa mga unang numbers ug ibalhin ang mas dagkong numbers aron ma-insert kini sa sakto nga lugar. Padayon kini hangtod ma-arrange ang array.



\## 3. Differences Between the Three Sorting Algorithms



Lahi-lahi ang proseso sa tulo ka sorting algorithms.



\- Bubble Sort – Nagkumpara sa magtapad nga numbers ug mag-usab sa ilang puwesto kung kinahanglan.

\- Selection Sort – Mangita una sa pinakagamay nga number ug ibutang kini sa sakto nga puwesto.

\- Insertion Sort – Magkuha og usa ka number ug isulod kini sa sakto nga lugar tunga-tunga sa mga numbers nga nahan-ay na.



Bisan lahi ilang pamaagi, parehas ra ang ilang resulta kung sakto ang implementation.



\## 4. Reflection Questions



\### 1. How does each sorting algorithm arrange numbers? What makes their processes different?



Ang Bubble Sort magkumpara sa magtapad nga numbers ug mag-usab kung kinahanglan. Ang Selection Sort mangita sa pinakagamay nga number ug ibutang sa sakto nga puwesto. Ang Insertion Sort magkuha og usa ka number ug ibutang kini sa saktong lugar. Lahi ilang proseso pero parehas ang ilang goal nga mahan-ay ang numbers.



\### 2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?



Para nako, ang Bubble Sort ang pinakasayon sabton ug buhaton kay sayon ra ang proseso. Magkumpara ra siya sa duha ka nagtapad nga numbers ug mausab kung dili sakto ang ilang order. Mas dali nako masabtan kung giunsa pag han-ay ang numbers.



\### 3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.



Ang Insertion Sort ang mas maayo kung daan nang sorted ang numbers. Dili na kinahanglan ibalhin ang mga numbers kay naa na sila sa sakto nga puwesto. Isa ra ka comparison ang kinahanglan sa mag sunod nga number.



\### 4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?



Kung magdugang og numbers sa array, mas daghan na ang kinahanglan i-compare ug i-arrange. Mahimong mas dugay ang pag-run sa sorting algorithms labi na kung daghan na kaayo ang numbers. Ang performance magdepende sad kung unsa kadaghan ang numbers ug unsa ka han-ay ang original array.



\### 5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?



Importante nga makasabot ta sa lain-laing sorting algorithms kay dili tanan parehas og performance. Isip future programmer, makatabang kini sa pagpili sa angay nga algorithm depende sa kahimtang ug kadaghan sa data. Mas makatabang pud kini sa pag-improve sa atong programming skills.
